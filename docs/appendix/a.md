# 附录A　猎头常用候选人评估维度速查表

## ——这是我们真正在评估什么

---

**使用说明**

这张表，是我做了十年猎头之后，整理出来的一套内部工作框架。

平时我们在候选人背后写的那些notes，打的那些标签，开的那些内部会议——本质上，都是在评估这几个维度。                

我把它公开出来，不是为了让求职者去"表演"这些维度，而是希望你真正理解：**猎头和面试官在看你的时候，脑子里在转什么。**

全表共分六大模块，每个模块下设若干子维度，每个子维度附有评估要点与常见危险信号。

适合在准备重要面试前，对照自查；也适合在收到拒信之后，复盘定位。

---

## 模块一：硬实力维度

> 这是门槛，过不了这一关，后面全部无效。

---

### 1.1 专业匹配度

**评估核心**：候选人的专业背景与目标岗位的实质契合程度，不只是title匹配，而是能力内核匹配。

| 评估要点 | 说明 |
|----------|------|
| 技能重叠度 | 简历里的核心技能与JD要求的交集，通常需要达到70%以上才有竞争力 |
| 行业经验的迁移性 | 跨行业候选人需要能清晰说明哪些能力可平移，哪些需要补课 |
| 深度 vs 广度 | 岗位需要的是专才还是通才？候选人的结构是否与此匹配 |
| 技术栈 / 工具链 | 尤其在技术类岗位，工具熟悉度会直接影响上手速度 |

**常见危险信号**
- 简历关键词堆砌，但追问时答不出细节
- 用平台规模代替个人贡献（"我们公司有百亿GMV"≠"我做了百亿GMV"）
- 频繁换赛道但每次都浅尝即止，没有形成任何深度

---

### 1.2 成果质量

**评估核心**：候选人过去创造的真实价值，有没有可被外部验证的硬产出。

| 评估要点 | 说明 |
|----------|------|
| 可量化成果 | 有没有具体数字支撑，规模、增长率、节约成本、提升效率等 |
| 个人贡献可分离性 | 这个成果里，候选人个人贡献占多少，是核心推手还是参与者 |
| 成果的持续性 | 是一次性项目成功，还是建立了可持续运行的机制、体系 |
| 难度系数 | 在什么样的资源条件和约束下取得的？逆境中的成果含金量更高 |

**常见危险信号**
- 只会说"我们团队做了……"，始终无法说清自己做了什么
- 所有成果都发生在资源极为充裕的大厂环境，脱离平台后未经检验
- 数字前后不一致，经不起追问

---

### 1.3 学习成长速度

**评估核心**：候选人历史上的迭代速度，能否在新环境里快速 ramp up。

| 评估要点 | 说明 |
|----------|------|
| 晋升节奏 | 在上一家公司的晋升速度是否优于平均水平 |
| 主动学习记录 | 有没有自驱完成的新技能获取，而非被动等待培训 |
| 跨域迁移案例 | 有没有把A领域的知识迁移到B领域的真实经历 |
| 失败后的复盘质量 | 候选人如何描述自己的失败，以及从中得到了什么 |

**常见危险信号**
- 在同一家公司同一岗位超过5年，无法说清这5年的成长点在哪里
- 所有知识来源都是"公司培训"，没有自驱学习的痕迹
- 描述失败时永远是外部原因，从不复盘自身问题

---

## 模块二：软实力维度

> 这是天花板。硬实力决定你能不能进场，软实力决定你能走多远。

---

### 2.1 沟通表达能力

**评估核心**：候选人能否将复杂信息清晰、准确、有说服力地传递给不同对象。

| 评估要点 | 说明 |
|----------|------|
| 结构化表达 | 说话有没有逻辑主线，能否在两分钟内说清一件复杂的事 |
| 对象感 | 能否根据听众调整表达方式（对技术人 vs 对业务人 vs 对老板） |
| 书面表达 | 简历、邮件、汇报文档的质量，折射真实的文字能力 |
| 倾听与回应 | 在面试中有没有真正听清问题再回答，而非自顾自输出 |

**常见危险信号**
- 说话永远没有重点，给10分钟，能扯出30分钟
- 用大量专业黑话回避实质性表达
- 面试官追问时，重复同样的答案而不是补充新信息

---

### 2.2 影响力与推动力

**评估核心**：候选人能否在没有直接汇报关系的情况下，推动事情落地。

| 评估要点 | 说明 |
|----------|------|
| 横向协作案例 | 有没有跨部门、跨团队的协作成果，而非只在自己的一亩三分地上成功 |
| 资源整合能力 | 能否在资源不足的情况下，通过人际关系和信用积累获取支持 |
| 向上管理 | 有没有有效影响过自己的上级，推动决策或资源倾斜 |
| 说服力来源 | 靠逻辑说服、靠数据说服，还是靠权力施压——前两者含金量更高 |

**常见危险信号**
- 所有成功案例都是"我直接管的团队做的"，缺乏横向影响力的体现
- 描述协作时频繁出现"其实是他们拖累了我们"的叙事
- 没有任何向上管理或影响决策层的经历

---

### 2.3 压力承受与情绪稳定性

**评估核心**：候选人在高压、不确定、模糊环境下的心理韧性。

| 评估要点 | 说明 |
|----------|------|
| 高压经历描述 | 有没有真实经历过高强度、高风险、高度不确定的处境 |
| 情绪调节记录 | 如何描述自己的低谷期，有没有崩溃、失控、甩锅的信号 |
| 面试现场稳定性 | 遇到刁钻问题、沉默、质疑时，候选人的即时反应 |
| 离职叙事 | 谈上一段经历时，有没有过度的情绪化表达，或明显的压抑回避 |

**常见危险信号**
- 谈及前公司或前老板时，情绪明显失控或充满怨怼
- 无法平静地描述任何一次失败或冲突
- 遇到压力面试时，防御机制过强，立刻进入自我保护模式

---

### 2.4 自我认知准确度

**评估核心**：候选人对自身优势、局限、价值观的认知是否客观、清醒。

这是我个人认为，所有维度里**最能区分候选人段位**的一个。

| 评估要点 | 说明 |
|----------|------|
| 优势描述的具体性 | "我执行力强"≠优势；"我在三个月内独立搭建了X体系"才是优势 |
| 局限的承认方式 | 能否主动、准确地说出自己的短板，而非表演式地"谦虚" |
| 价值观的清晰度 | 能否说清楚自己选择一份工作时，真正看重什么，为什么 |
| 自我评价与外部反馈的一致性 | 候选人说的"我的风格"，与他人描述的"他的风格"是否吻合 |

**常见危险信号**
- 优势全是"我工作认真负责、学习能力强"——人人都这么说
- 说缺点时清一色"我太追求完美""我工作太拼了"——这是包装，不是认知
- 对离职原因的描述与实际经历明显对不上

---

## 模块三：动机与稳定性维度

> 这是风险控制。企业花时间和成本招一个人，他们不想六个月后重来一遍。

---

### 3.1 跳槽动机的真实性

**评估核心**：候选人这次为什么要走，以及他说的理由是否可信。

| 评估要点 | 说明 |
|----------|------|
| 主动离职 vs 被动离职 | 两者都可以接受，但需要诚实，被抓到撒谎是一票否决 |
| push因素 vs pull因素 | 逃离型动机（因为现在不好）vs 吸引型动机（因为那边更好），后者更健康 |
| 动机与目标岗位的匹配度 | 说"想做大规模系统"，却投了一个小团队的岗位，逻辑不自洽 |
| 离职节点的合理性 | 在项目关键节点离职，需要给出令人信服的解释 |

**常见危险信号**
- 换了多种说法都无法清晰解释为什么现在要走
- 动机明显只是钱，但又试图掩盖这一点（钱本身不是问题，掩饰才是）
- 对目标公司的研究浮于表面，说不出真实的吸引点

---

### 3.2 历史稳定性

**评估核心**：候选人过去的工作年限分布，是否显示出持续性和深耕能力。

| 评估要点 | 说明 |
|----------|------|
| 平均在职时长 | 行业标准通常是2～4年为正常，1年以内的频繁更换需要解释 |
| 短暂工作经历的解释 | 有没有合理的背景原因（公司倒闭、行业洗牌、个人重大变故） |
| 上升性 vs 平行性 | 每次跳槽是否有明显的向上发展，还是在同一层级横向移动 |
| 试用期通过率 | 如有多段短暂经历，是否有试用期未通过的情况 |

**常见危险信号**
- 五年内四家公司，每家都不到一年，且无法给出有说服力的解释
- 每次离职都是"公司方向有问题"，从不提自己的适配问题
- 加入时的岗位级别低于上一份工作，但无法解释降级原因

---

### 3.3 对目标公司 / 岗位的真实兴趣

**评估核心**：候选人对这家公司的兴趣，是真实的还是海投式的。

| 评估要点 | 说明 |
|----------|------|
| 公司研究深度 | 能否准确说出公司近期的战略动向、产品方向、组织变化 |
| 行业认知 | 对这个行业的理解是否超过新闻层面，有没有自己的判断 |
| 岗位理解 | 对目标岗位的核心挑战有没有真实的预判，而非只看JD说话 |
| 提问质量 | 候选人反问面试官的问题，是否显示出真实的思考和兴趣 |

**常见危险信号**
- 对公司的了解停留在"贵公司是行业领先……"这种官网语言
- 无法说出为什么选这家而不是竞品公司
- 问的问题全是"请问公司有没有食堂""加班多不多"——这些没问题，但如果这是全部，则说明缺乏实质兴趣

---

## 模块四：领导力与管理维度

> 仅适用于有团队管理要求的岗位。纯执行岗位可跳过此模块。

---

### 4.1 团队建设能力

**评估核心**：候选人招人、育人、留人的能力与记录。

| 评估要点 | 说明 |
|----------|------|
| 团队规模与质量 | 管过多少人，这些人的整体质量如何，有没有培养出优秀下属 |
| 招聘判断力 | 候选人如何描述自己招人的标准，是否清晰、可执行 |
| 下属发展记录 | 有没有具体的"我培养了谁、他们后来去了哪里"的案例 |
| 团队氛围营造 | 团队的离职率、士气、协作质量，候选人有没有主动经营过这些 |

**常见危险信号**
- 管过的下属，没有一个他能清晰讲出成长轨迹的
- 描述团队时，所有失误都归因于下属能力不足
- 对"你如何处理绩效不达标的员工"这类问题完全没有经验和思路

---

### 4.2 决策质量

**评估核心**：候选人在信息不完整、时间紧迫的情况下，做决策的方式与质量。

| 评估要点 | 说明 |
|----------|------|
| 决策框架 | 有没有一套相对稳定的决策方法论，而非纯靠直觉 |
| 风险意识 | 做决策时有没有主动识别和评估风险，而非只看上行 |
| 决策速度 | 能否在有限信息下果断行动，而非陷入分析瘫痪 |
| 决策复盘 | 有没有事后复盘错误决策、修正判断框架的习惯 |

**常见危险信号**
- 描述的所有决策都是正确的，没有任何错误决策的案例
- 重大决策完全依赖上级授权，从不主动判断
- 遇到复杂问题时，思维明显停滞，无法在有限时间内给出有结构的判断

---

### 4.3 向上管理与跨级沟通

**评估核心**：候选人与上级及更高层的协作方式，有没有有效向上影响的能力。

| 评估要点 | 说明 |
|----------|------|
| 上级关系质量 | 与历任上级的关系如何，有没有真实的信任积累 |
| 争取资源的方式 | 如何为团队争取资源，靠理性说服、关系运营还是行政手段 |
| 处理分歧的方式 | 与上级意见不合时，如何处理，是服从、说服还是回避 |
| 高管接触经验 | 有没有直接与C-level汇报或协作的经历，是否适应这种节奏 |

**常见危险信号**
- 谈到所有前任上级，都是负面评价，且模式高度一致
- 从未主动推动过任何需要跨级沟通的事项
- 描述高管互动时，明显不适或回避，暗示缺乏这类经验

---

## 模块五：文化与价值观适配维度

> 这是隐性门槛，但淘汰率极高。很多候选人能力很强，就死在这里。

---

### 5.1 工作风格与企业文化的匹配

**评估核心**：候选人的工作方式、节奏偏好，与目标公司的文化是否兼容。

| 文化类型 | 适合的候选人特征 |
|----------|------------------|
| 高速迭代型（字节、拼多多风格） | 耐受模糊、行动优先、不依赖流程、能接受高频变化 |
| 精细化管理型（阿里、华为风格） | 文档意识强、流程规范、数据驱动、习惯体系化操作 |
| 创业初期型（A/B轮） | 能从零搭建、资源紧、角色杂、有强烈的主人翁意识 |
| 成熟大型组织（央企、外企） | 耐受官僚流程、长期主义、重关系和资历、节奏稳定 |

**常见危险信号**
- 候选人来自阿里，投创业公司，却无法描述任何"从零开始"的经历
- 候选人来自小团队，投大厂，无法适应流程和汇报体系
- 对目标公司文化的了解，仅停留于公开PR层面

---

### 5.2 价值观冲突风险

**评估核心**：候选人的核心价值观与目标公司有没有根本性的冲突。

| 评估要点 | 说明 |
|----------|------|
| 对加班文化的真实态度 | 说能接受，但历史经历显示只做过正常节奏工作，要小心 |
| 对"结果导向"的理解 | 有些人理解为"不择手段"，有些人理解为"以价值为核心"，差异巨大 |
| 对权威的态度 | 是习惯服从权威，还是习惯质疑权威，需要与目标公司风格对齐 |
| 对竞争的态度 | 团队内部强竞争文化 vs 协作文化，候选人倾向哪种 |

**常见危险信号**
- 说"我最看重工作生活平衡"，却投了一家以"拼命文化"著称的公司
- 描述理想工作环境时，与目标岗位现实高度不符，却没有意识到
- 价值观表述过于完美，像在背面试答案，缺乏真实生活经验的支撑

---

## 模块六：发展潜力维度

> 这是对未来的赌注，尤其在校招和年轻候选人的评估中权重最高。

---

### 6.1 成长天花板判断

**评估核心**：这个人未来还能成长多少，以及成长的驱动力来自哪里。

| 评估要点 | 说明 |
|----------|------|
| 好奇心密度 | 候选人对新事物、新领域的真实兴趣，是否超出工作需要 |
| 自我驱动记录 | 有没有纯粹出于自驱、在无人要求的情况下做出的成长行动 |
| 元认知能力 | 候选人能否清醒地分析自己的思维模式和学习方式 |
| 对挑战的渴望程度 | 主动寻求挑战，还是习惯待在舒适区，哪怕已经做得足够好 |

**常见危险信号**
- 谈及未来发展，只谈职位晋升和薪资，对能力成长没有具体想法
- 过去五年，除了工作项目，没有任何自驱成长的痕迹
- 遇到"你五年后想成为什么样的人"类问题，完全无法回答或答案极度空洞

---

### 6.2 跨界整合潜力

**评估核心**：候选人是否具备将不同领域知识融合、产生新洞见的能力。

| 评估要点 | 说明 |
|----------|------|
| 兴趣广度 | 工作之外有没有深度爱好，这往往是跨界思维的来源 |
| 类比思维 | 能否用A领域的思维框架来解释B领域的问题 |
| 多元背景 | 有没有跨行业、跨地域、跨文化的经历，这是认知多样性的重要来源 |
| 问题建构方式 | 面对复杂问题，是套用现成框架，还是能重新定义问题本身 |

**常见危险信号**
- 兴趣爱好一栏永远是"读书、健身、旅游"——这不是爱好，是填充物
- 思维方式高度路径依赖，只能在既有框架内操作
- 从未有过任何跨界经历，且对此没有任何主动兴趣

## 综合评估说明

### 猎头内部的四象限判断模型

在实际工作中，我们会把候选人快速归入以下四种类型，再决定如何推进：

```
              高潜力
                │
    可培养型    │    明星型
   （扶持推进） │  （优先推荐）
                │
低能力 ─────────┼───────── 高能力
                │
    放弃型      │    老黄牛型
  （不推进）    │ （视岗位匹配推进）
                │
              低潜力
```

**明星型**：现有能力强，未来潜力高——优先推荐，快速推进

**可培养型**：现有能力一般，但潜力信号明显——适合有培养机制的客户，推荐时需说明

**老黄牛型**：现有能力强，但成长天花板明显——适合执行型岗位，不适合管理或创新岗位

**放弃型**：能力和潜力双低——不推进，坦诚告知

### 关于这张表的最后一点说明

这张表不是用来"表演"的。

我见过候选人，提前研究了猎头和面试官的评估逻辑，然后把每一个维度都"备了课"，面试时对答如流，光鲜得像一份完美的PPT。

但入职三个月，就原形毕露了。

**表演能通过面试，但通不过真实的工作。**

这张表真正的用途，是帮你诚实地照镜子——

哪些维度，你是真的强？

哪些维度，你有明显的短板？

哪些维度，你从来没认真想过？

想清楚这些，比背会所有面试答案，有用得多。
