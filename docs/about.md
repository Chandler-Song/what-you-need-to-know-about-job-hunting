# 关于

## 写作初衷

在多年的求职辅导和职业咨询实践中，我发现一个反复出现的问题：**大多数求职者并非能力不足，而是缺乏系统性的求职方法论**。

他们可能技术过硬，却不会写简历；可能经验丰富，却在面试中词不达意；可能手握多个 Offer，却不知如何抉择；可能权益受损，却浑然不觉。

这本书的诞生，就是为了填补这个空白。

> 我们希望每一位求职者都能掌握从简历到入职的全流程技能，在职业起点就做出最明智的选择。

# 第一部分：祛魅——把求职这件事看清楚

> **核心命题**：在开始任何动作之前，先把幻觉打碎。

### 第二章　市场不骗人，只是你没看懂它

**2.1** 什么叫"人才市场行情"——你的身价是被供需关系决定的，不是被努力决定的

**2.3** 大厂光环的真相：为什么有些人离开大厂，反而变得"不值钱"了

### 第三章　人性的暗面在招聘里——你必须知道

**3.2** 晕轮效应、确认偏见、相似性吸引：你的命运在前5分钟就定了？

**3.4** 用人部门 vs HR：两个话语体系，两套评价标准，谁说了算？

# 第二部分：备战——上场之前先做人前的功课

**4.4** 弱点的正确处理方式：承认它、框架它、超越它
**4.5** 两种人最难帮：过度自信者与长期自我否定者——你是哪种？

### 第五章　目标清单——你到底要去哪里？

**5.4** 城市、行业、赛道的三角选择：哪个维度优先，为什么

### 第八章　第一轮：HR面——通过筛选的生存法则

### 第九章　第二轮：业务面——跟真正的决策者过招
