# 关于本书

## 写作初衷

在多年的求职辅导和职业咨询实践中，我发现一个反复出现的问题：**大多数求职者并非能力不足，而是缺乏系统性的求职方法论**。

他们可能技术过硬，却不会写简历；可能经验丰富，却在面试中词不达意；可能手握多个 Offer，却不知如何抉择；可能权益受损，却浑然不觉。

这本书的诞生，就是为了填补这个空白。

> 我们希望每一位求职者都能掌握从简历到入职的全流程技能，在职业起点就做出最明智的选择。

## 本书特色

::: info 实战导向
不讲空洞理论，每一个观点都有真实案例支撑，每一个方法都可以直接拿去用。从简历撰写的 STAR 法则到薪资谈判的锚定效应，全书都是可落地的操作指南。
:::

::: info 系统全面
覆盖求职全流程——从认知祛魅、自我定位、简历撰写、面试应对到薪资谈判和职业规划。不是零散的技巧合集，而是一套完整的求职方法论体系。
:::

::: info 即查即用
每章独立成篇，可以根据你当前所处的求职阶段选择性阅读。无论是正在准备面试还是面临 Offer 选择，都能快速找到对应的实用指南。
:::

::: info 法律护航
专门设置劳动合同与权益保护章节，涵盖经济补偿金、竞业限制、试用期陷阱等关键法律知识，帮助求职者识别和规避常见的法律风险。
:::

## 内容概览

全书分为 **5 大部分 · 16 章 · 79 节**，外加终章与 5 篇附录工具包。

| 部分 | 主题 | 核心内容 |
|------|------|----------|
| 第一部分 | 祛魅 | 看清求职本质：信息不对称、市场定价、招聘真相 |
| 第二部分 | 备战 | 做好功课：自我认知、目标定位、简历打磨 |
| 第三部分 | 出牌 | 面试实战：HR面、业务面、终面、面试心理学 |
| 第四部分 | 谈判 | 终局博弈：薪资谈判、Offer决策、优雅离职 |
| 第五部分 | 进化 | 长期主义：职业复盘、护城河、从猎物到猎手 |

> **终章**：求职的尽头，是认识你自己。
>
> **附录**：猎头评估维度速查表 / 30个高频面试题拆解 / 薪资谈判话术模板 / 背调问题标准库 / 推荐阅读书单
