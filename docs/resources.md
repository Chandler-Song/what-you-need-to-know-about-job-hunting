## 法律维权资料

### 合同审查清单

签订劳动合同前的 20 项检查清单，确保你的合同合法合规：

1. ✅ 用人单位信息完整
2. ✅ 合同期限明确
3. ✅ 试用期符合法定上限
4. ✅ 薪资结构清晰（基本 + 绩效 + 补贴）
5. ✅ 工作地点具体明确
6. ✅ 社保公积金缴纳基数约定
7. ✅ 竞业限制条款合理
8. ✅ 违约金条款合法
9. ✅ 合同份数正确（一式两份）
10. ✅ 无空白待填项

### 试用期权益速查卡

一张卡片快速了解试用期核心权益：

| 权益项 | 标准 |
|--------|------|
| 试用期时长 | 根据合同期限，最长 6 个月 |
| 试用期工资 | ≥ 同岗位最低档 80%，且 ≥ 最低工资 |
| 社保缴纳 | 试用期内必须缴纳 |
| 解除合同 | 提前 3 天通知即可 |
| 被辞退补偿 | 适用经济补偿金规定 |
