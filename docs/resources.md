## 候选人评估维度速查表

> 来源：附录A《猎头常用候选人评估维度速查表》

了解猎头和面试官在评估你时，脑子里在转什么。这不是让你去"表演"，而是帮你诚实地照镜子。

### 六大评估模块总览

| 模块 | 核心问题 | 子维度 |
|------|----------|--------|
| **硬实力** | 这是门槛，过不了这一关后面全部无效 | 专业匹配度、成果质量、学习成长速度 |
| **软实力** | 这是天花板，决定你能走多远 | 沟通表达、影响力与推动力、压力承受、自我认知准确度 |
| **动机与稳定性** | 这是风险控制，企业不想六个月后重来 | 跳槽动机真实性、历史稳定性、对目标公司的真实兴趣 |
| **领导力与管理** | 仅适用于有团队管理要求的岗位 | 团队建设、决策质量、向上管理与跨级沟通 |
| **文化与价值观适配** | 这是隐性门槛，淘汰率极高 | 工作风格匹配、价值观冲突风险 |
| **发展潜力** | 这是对未来潜力的判断 | 成长天花板、跨界整合潜力 |

### 四象限判断模型

猎头内部会将候选人快速归入四种类型：

| 类型 | 能力 | 潜力 | 策略 |
|------|------|------|------|
| **明星型** | 高 | 高 | 优先推荐，快速推进 |
| **可培养型** | 一般 | 高 | 适合有培养机制的客户 |
| **老黄牛型** | 高 | 低 | 适合执行型岗位 |
| **放弃型** | 低 | 低 | 不推进，坦诚告知 |

::: warning 使用建议
这张表真正的用途，是帮你诚实地照镜子——哪些维度你是真的强？哪些维度你有明显短板？哪些维度你从来没认真想过？想清楚这些，比背会所有面试答案有用得多。
:::

## 面试准备工具箱
> 来源：附录B《30个高频面试题与底层逻辑拆解》

### 7 天面试准备计划

一份结构化的面试准备时间表，帮助你在面试前一周系统性地完成各项准备：

| 天数 | 准备内容 | 预计时长 |
|------|----------|----------|
| Day 1 | 研究目标公司（产品、文化、近期新闻、战略动向） | 2 小时 |
| Day 2 | 梳理个人经历，准备 STAR 案例（成就、失败、冲突各一个） | 2 小时 |
| Day 3 | 练习高频面试问题，重点攻克自我介绍和离职动机 | 3 小时 |
| Day 4 | 模拟面试（找朋友或使用录音练习），注意追问环节 | 2 小时 |
| Day 5 | 准备反问环节的八类问题，研究面试官背景 | 1 小时 |
| Day 6 | 复习笔记，查漏补缺，整理薪资谈判策略 | 2 小时 |
| Day 7 | 轻松复习，准备面试当天物品，调整心态 | 1 小时 |

### 30 道高频面试题分类速查

以下是从十年猎头实战中筛选出的最高频、最有区分度的 30 道面试题，按七大类别归纳：

| 类别 | 题号 | 核心问题 |
|------|------|----------|
| **关于你这个人** | Q1-Q5 | 自我介绍、最大优势、最大缺点、三个词描述自己、职业规划 |
| **关于你的经历** | Q6-Q10 | 最有成就感的项目、最大失败、人际冲突、反对上级、多优先级管理 |
| **离职与动机** | Q11-Q13 | 为什么离开、为什么选我们、还在面试其他公司吗 |
| **能力与方法论** | Q14-Q18 | 融入新环境、决策方式、处理模糊性、团队管理、给下属反馈 |
| **关于这个岗位** | Q19-Q20 | 岗位最大挑战、入职头三个月计划 |
| **薪资与谈判** | Q21-Q22 | 期望薪资、目前薪资 |
| **反向提问** | Q23-Q30 | 成功标准、核心挑战、团队协作、面试官经历、公司方向、文化真相、前任去向、下一步流程 |

::: tip 面试回答的总原则
面试官想知道，你是一个**真实的人**，还是一个经过精心包装的简历。最好的面试回答，不是最完美的回答，而是**最真实、最有结构**的回答。真实让人信任，结构让人理解，两者合一，才是面试里真正的竞争力。
:::

### 每道题的应答框架

每道面试题，你需要掌握三个要素：

1. **底层逻辑** —— 面试官问这个问题，真正想知道什么
2. **优质回答结构** —— 不是标准答案，是思维框架
3. **致命错误** —— 哪些回答方式，会让你直接出局

::: warning 核心方法论
不要试图背答案。答案背出来是假的，一追问就穿帮。你要内化的，是面试官的思维逻辑——知道他在看什么，你才能把真实的自己，用他听得懂的语言呈现出来。
:::

## 薪资谈判实战手册

> 来源：附录C《薪资谈判话术模板（分场景）》

### 谈判四阶段全景图

| 阶段 | 场景 | 核心策略 |
|------|------|----------|
| **信息收集** | HR 第一次问期望薪资 / 猎头询问薪资 / 了解薪酬结构 | 让对方先出牌，摸清 package 全貌 |
| **报价锚定** | 被迫先报数字 / 对方报价低于预期 / 被问有无其他 offer | 报区间不报单一数字，有依据地锚定 |
| **推进周旋** | 对方迟迟不回音 / offer 低于期望 / 谈判僵局 / 被问"最在乎什么" | 用非现金要素打破僵局，保持存在感 |
| **收尾决策** | 多 offer 协调时间 / 最终确认细节 | offer 是起点不是终点，确认一切书面化 |

### 谈判十条元原则

::: tip 比任何话术都重要的十条底线

1. **沉默是筹码，不是尴尬** —— 对方报价后，停顿两三秒是完全合理的思考
2. **永远谈 package，不只谈底薪** —— 多维谈判总能找到更多解法
3. **第一个报价的人，设定了谈判地图** —— 尽量让对方先报，必须先报时报区间
4. **理由比数字更重要** —— "我期望X，因为……"比"我期望X"有力得多
5. **谈判是合作，不是对抗** —— 保持善意和专业，比任何技巧都重要
6. **不要让步，除非换来对等的东西** —— 让步要换让步，不要单方面退让
7. **截止日期是真实的压力来源** —— 学会合理使用时间压力，但不制造虚假紧迫感
8. **情绪是谈判的大敌** —— 无论多失望或多惊喜，保持语气平稳
9. **背调是真实的** —— 不要在任何数字上撒谎
10. **接受是一个决定，不是一场投降** —— 综合判断后接受，不是因为谈累了
:::

### 薪资总包计算器

帮你计算 Offer 的真实价值：

- 基本薪资 + 年终奖 + 股权折算
- 社保公积金（不同基数对比）
- 通勤成本扣除
- 加班时薪折算
- 试用期折扣计算

## 背调通关指南

> 来源：附录D《背调问题标准库》

### 背调的五个标准维度

专业背调通常覆盖以下五个维度：

| 维度 | 调查内容 | 权重 |
|------|----------|------|
| 基本信息核实 | 在职时间、职位、汇报关系、离职原因 | 基础 |
| 工作表现 | 业绩、能力、贡献、团队协作 | 核心 |
| 人品与职业操守 | 诚信、承诺兑现、有无重大争议事件 | 关键 |
| 管理风格 | 带团队方式、下属评价、决策方式（仅管理岗） | 条件 |
| 离职真实原因 | 与候选人自述是否一致 | 关键 |

### 被背调前必须做的五件事

| 序号 | 准备事项 | 要点 |
|------|----------|------|
| ① | 确认参考人 | 事先联系对方，告知求职情况，不要让参考人被突然来电吓到 |
| ② | 统一叙事 | 面试说法与参考人说法必须基本一致，尤其是离职原因和项目角色 |
| ③ | 选对参考人 | 优先选择直接共事的前上级，能说具体内容的人，关系真实可信的人 |
| ④ | 准备解释"敏感点" | 短暂任职、降级跳槽、履历空白、被辞退、劳动纠纷——都需要自洽解释 |
| ⑤ | 确认无简历造假 | 学历、任职时间、职位名称、项目参与度——任何造假都会被专业背调发现 |

::: danger 关键警示
旁路背调（不经过候选人提供的参考人，直接联系简历上公司的相关人员）是真实存在的。尤其对高级候选人，背调方会主动通过领英或内部人脉找到你的前同事。
:::

### 背调问题标准库（30 题）

背调者视角的七模块标准问题库：

| 模块 | 题号 | 覆盖内容 |
|------|------|----------|
| 基本信息核实 | Q1-Q4 | 关系确认、职位核实、离职时间、薪资验证 |
| 工作表现与能力 | Q5-Q10 | 项目角色、核心优势、工作质量、改进空间、稳定性、工作风格 |
| 人品与职业操守 | Q11-Q14 | 诚信记录、承诺兑现、人际关系、信任度综合评价 |
| 离职原因深挖 | Q15-Q17 | 离职动机、同事反应、公司是否想留 |
| 协作与沟通 | Q18-Q20 | 跨部门协作、沟通方式、高压表现 |
| 管理能力 | Q21-Q25 | 带团队方式、培养下属、决策风格、处理失误、向上管理 |
| 综合评估 | Q26-Q30 | 再次合作意愿、最佳环境、遗漏信息、一句话总结、信息确认 |

## Offer 评估工具

### Offer 对比评分表

基于本书第三章的五维评估矩阵设计的评分框架：

| 评估维度 | 权重 | 评估要点 |
|----------|------|----------|
| 薪资总包 | 25% | 底薪 + 奖金 + 股权 + 福利的年化总价值 |
| 职业发展 | 25% | 晋升通道、技能成长、行业前景 |
| 公司平台 | 20% | 公司规模、行业地位、团队质量 |
| 工作生活平衡 | 15% | 加班强度、通勤距离、弹性工作 |
| 文化适配 | 15% | 管理风格、团队氛围、价值观契合度 |

支持多 Offer 横向对比与可视化雷达图展示。

### 合同审查清单

签订劳动合同前的核心检查项：

| 序号 | 检查项 | 要点 |
|------|--------|------|
| 1 | 用人单位信息完整 | 公司全称、注册地址、法定代表人 |
| 2 | 合同期限明确 | 固定期限/无固定期限，起止日期 |
| 3 | 试用期符合法定上限 | 3年合同≤6个月，1年合同≤2个月 |
| 4 | 薪资结构清晰 | 基本工资 + 绩效 + 补贴分项列明 |
| 5 | 工作地点具体明确 | 城市 + 具体地址，防止随意调岗 |
| 6 | 社保公积金缴纳基数 | 按实际工资缴纳还是最低基数 |
| 7 | 竞业限制条款 | 范围、期限、补偿金是否合理 |
| 8 | 违约金条款 | 仅培训服务期和竞业限制可约定违约金 |
| 9 | 合同份数 | 一式两份，你手里必须有一份 |
| 10 | 无空白待填项 | 所有空白处划掉或填写"无" |

### 试用期权益速查卡

| 权益项 | 法定标准 |
|--------|----------|
| 试用期时长 | 根据合同期限，最长 6 个月 |
| 试用期工资 | ≥ 同岗位最低档 80%，且 ≥ 当地最低工资 |
| 社保缴纳 | 试用期内必须缴纳，不得以试用期为由拒绝 |
| 解除合同 | 提前 3 天通知即可（转正后需 30 天） |
| 被辞退补偿 | 适用经济补偿金规定，不得低于法定标准 |
